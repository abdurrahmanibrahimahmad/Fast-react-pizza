# Fast React Pizza

Fast React Pizza is a modern pizza ordering web app built with React, Redux, and an external API. The app allows users to browse and order pizza from a menu, track their location, and complete orders with ease. The application uses Redux for state management, enabling smooth and consistent updates across the app.
## Live Demo 👎
[Fast-React-Pizza](https://fast-react-pizza-dev.vercel.app/)
## Features

- **Pizza Ordering**: Browse the pizza menu and add pizzas to your order.
- **Location Tracking**: The app can provide your current location.
- **State Management**: Redux is used for efficient state management and data flow.
- **Responsive UI**: Built with HTML, CSS, and React to provide a seamless experience across devices.

## Technologies Used

- **HTML5** for the structure of the page.
- **CSS3** for styling the app.
- **JavaScript** (ES6+) for functionality.
- **React** for building the user interface.
- **Redux** for state management.
- **Pizza API** for fetching pizza menu and order details.

## Setup and Installation

To get a local copy of the project up and running, follow these simple steps:

### Prerequisites

- [Node.js](https://nodejs.org/) (v14 or higher) and npm (comes with Node.js) should be installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/abdurrahmanibrahimahmad/Fast-react-pizza.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Fast-react-pizza
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Run the application locally:
   ```bash
   npm start
   ```

   The app should now be running on [http://localhost:3000](http://localhost:3000).

## Usage

1. Open the app in your browser.
2. Browse the pizza menu and add pizzas to your order.
3. The app will automatically track your location.
4. Complete the order and enjoy your pizza!

## API Used

This project fetches pizza data from a public pizza API. The API provides details about the available pizzas, including name, description, price, and image.
